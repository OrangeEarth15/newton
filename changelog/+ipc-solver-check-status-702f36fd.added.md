Add ``SolverIPC.check_status`` for callers that capture ``SolverIPC.step`` in a CUDA graph, where a failed step cannot raise: run after a replay with the ``STATUS`` observables the steps wrote, it raises ``RuntimeError`` when a step failed, warns with ``NewtonWarning`` when one reached an iteration limit, and with ``grow=True`` enlarges the contact lists after an overflow and returns ``True``. The ``cloth_ipc`` example checks every substep this way and repeats a frame that overflowed.
